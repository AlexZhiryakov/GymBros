# Политика конфиденциальности сервиса GymBros

Редакция от 2 ноября 2026 г.

Настоящая Политика определяет порядок обработки персональных данных пользователей Telegram-бота **GymBros** (`@OfficialGymBrosBot`) в соответствии с Федеральным законом РФ от 27.07.2006 № 152-ФЗ «О персональных данных».

## 1. Оператор персональных данных

- **Оператор:** Жиряков Александр (физлицо; значение можно переопределить через `OPERATOR_NAME`).
- **Контакты:** `alexzhiryakov17@mail.ru`, Telegram `@gymbros_manager`
  (переопределяются через `OPERATOR_EMAIL` / `OPERATOR_TELEGRAM`).
- **Сервис:** Telegram-бот GymBros для поиска напарника для тренировок.

Актуальные реквизиты также отображаются в боте по команде `/privacy`.

## 2. Какие данные обрабатываются

| Категория | Примеры |
|---|---|
| Идентификаторы Telegram | `telegram_id`, username |
| Анкетные данные | имя, возраст, пол, город, стаж, описание |
| Медиа | фото и/или видео анкеты (file_id Telegram) |
| Данные о зале | название зала, улица |
| Поведенческие данные | лайки, дизлайки, просмотры, реферальные связи |
| Технические | дата создания/обновления анкеты, статусы подписки |

Специальные категории персональных данных (биометрия в смысле 152-ФЗ, сведения о здоровье и т.п.) **намеренно не запрашиваются**. Фото/видео используются как содержимое анкеты, а не как биометрическая идентификация.

## 3. Цели обработки

1. Создание и показ анкеты другим пользователям сервиса.
2. Подбор совместимых напарников по залу/городу/предпочтениям.
3. Уведомления о взаимном интересе (лайки) внутри Telegram.
4. Обеспечение безопасности, модерация и поддержка пользователей.
5. Исполнение требований законодательства РФ.

Правовое основание: **согласие субъекта персональных данных** (ст. 6, ст. 9 152-ФЗ), предоставляемое в боте до создания анкеты.

## 4. Порядок и способы обработки

Обработка включает сбор, запись, систематизацию, хранение, уточнение, использование, передачу (предоставление другим пользователям бота в объёме анкеты), блокирование, удаление и уничтожение.

Обработка осуществляется с использованием средств автоматизации (серверы приложения и СУБД).

## 5. Передача данных третьим лицам

- Другим пользователям GymBros передаются данные, которые пользователь сам указал в анкете (для цели знакомства для тренировок).
- Инфраструктурным провайдерам (хостинг приложения, PostgreSQL), действующим по поручению оператора.
- Telegram (мессенджер, через который работает бот) — в соответствии с условиями Telegram.
- Государственным органам — только в случаях, прямо предусмотренных законом РФ.

Трансграничная передача возможна, если инфраструктура оператора расположена за пределами РФ (например, облачная БД). Используя сервис, пользователь соглашается с такой передачей в объёме, необходимом для работы бота.

## 6. Сроки хранения

Данные хранятся до:

- отзыва согласия и/или удаления анкеты пользователем (`/delete_my_data`);
- удаления анкеты оператором при нарушении правил;
- прекращения работы сервиса.

После удаления анкеты персональные данные уничтожаются из рабочей базы в разумный срок, необходимый для технической очистки, за исключением сведений, которые оператор обязан хранить по закону.

## 7. Права пользователя

Пользователь вправе:

- получать информацию об обработке своих данных;
- требовать уточнения, блокирования или уничтожения данных;
- отозвать согласие на обработку.

Для реализации прав используйте:

- `/privacy` — краткая информация;
- `/delete_my_data` — удаление анкеты и связанных данных;
- обращение на email оператора или в Telegram поддержки.

## 8. Меры защиты

Оператор принимает организационные и технические меры: ограничение доступа к БД, хранение секретов вне репозитория, использование защищённого соединения с БД (TLS), разграничение прав администратора.

## 9. Возраст

Сервис предназначен только для лиц, достигших **18 лет**. Создавая анкету, пользователь подтверждает достижение этого возраста.

## 10. Изменение Политики

Оператор может обновлять Политику. Актуальная версия публикуется в репозитории проекта и/или доступна по команде `/privacy`. Продолжение использования сервиса после публикации новой редакции означает согласие с изменениями в части, не требующей отдельного согласия по закону.

## 11. Контакты
