# Пользовательское соглашение сервиса GymBros

Редакция от 2 ноября 2026 г.

## 1. Общие положения

1.1. Настоящее Соглашение регулирует использование Telegram-бота **GymBros** (`@OfficialGymBrosBot`).
1.2. Начиная пользоваться ботом и принимая согласие на обработку персональных данных, пользователь присоединяется к условиям Соглашения.
1.3. Сервис предоставляет функциональность поиска напарника для тренировок (профили, лайки, уведомления).

## 2. Возраст и правоспособность

2.1. Сервис доступен только лицам старше **18 лет**.
2.2. Пользователь гарантирует достоверность указываемых сведений.

## 3. Правила поведения

Запрещается:

- оскорбления, угрозы, дискриминация;
- спам, реклама без согласия оператора, мошенничество;
- публикация чужих персональных данных и фото без согласия;
- контент, нарушающий законы РФ;
- создание фейковых анкет в целях обмана.

Оператор вправе удалить анкету и ограничить доступ без компенсации.

## 4. Подписки

Платные функции (Premium/VIP), если доступны, оформляются через поддержку и не продлеваются автоматически, если иное прямо не указано при оплате.

## 5. Персональные данные

Обработка персональных данных осуществляется согласно [Политике конфиденциальности](./PRIVACY_POLICY.md) и согласию, которое пользователь даёт в боте.

## 6. Отказ от гарантий

Сервис предоставляется «как есть». Оператор не гарантирует подбор напарника, бесперебойную работу и сохранность данных при сбоях третьих сторон (Telegram, хостинг, БД).

## 7. Ответственность

Пользователь самостоятельно несёт ответственность за общение и встречи, организованные через сервис. Оператор не является организатором офлайн-встреч и не проверяет пользователей сверх технических возможностей модерации.

## 8. Удаление данных и прекращение использования

Пользователь может удалить анкету командой `/delete_my_data` или через поддержку. Это означает отзыв согласия на обработку в отношении удаляемых данных.

## 9. Изменения

Оператор может обновлять Соглашение, публикуя новую редакцию в репозитории. Существенные изменения доводятся через бота по возможности.
